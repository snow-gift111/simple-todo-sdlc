# User Guide

## Clear Completed Todo Items

The **Clear Completed** action is available on the main Todo list screen.

### When the Button Appears

The **Clear Completed** button appears only when at least one Todo item is marked completed.

### How to Use It

1. Mark one or more Todo items as completed using the existing completion control.
2. Select **Clear Completed**.
3. Completed Todo items are removed from the list.
4. Incomplete Todo items remain visible and unchanged.

### Expected Behavior

- Completed Todo items are removed in one action.
- Incomplete Todo items are not removed.
- When no completed Todo items remain, the **Clear Completed** button is no longer shown.
- Existing Todo actions, including add, toggle complete/incomplete, edit, sort, and individual delete, continue to work as before.
