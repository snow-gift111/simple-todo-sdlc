# Setup Guide

## Prerequisites

- Node.js and npm installed.
- Repository cloned locally.

## Installation

```bash
npm install
```

## Run Locally

```bash
npm start
```

Open [http://localhost:3000](http://localhost:3000) in a browser.

## Run Tests

```bash
npm test -- --watchAll=false
```

## Build

```bash
npm run build
```

The build output is generated in the `build/` folder.
